# scope — เวลาฝนเริ่ม / หนักสุด / หยุด (ขั้น 5 ของ pipeline)

ทาย **เวลาที่ฝนจะเริ่ม ตกหนักที่สุด และหยุด** ที่จุดบนพื้น พร้อมช่วงความไม่แน่นอน 50 % / 80 %
จากภาพอินฟราเรดของ Himawari อย่างเดียว (B13 10.4 µm และ B15 12.4 µm) ร่วมกับ track ของเมฆจากขั้น 3
ทุกค่าที่ใช้รู้ได้ ณ เวลาภาพนั้น (ใช้แค่ภาพปัจจุบันและภาพก่อนหน้า ≤ 30 นาที) จึงรันแบบ real-time ได้

## 2. นาฬิกาเมฆ t0 และสายตระกูล

- **t0 ของ track = scan แรกที่แกนลึก (B13 < 235 K) มีอย่างน้อย 4 พิกเซล** คือจังหวะที่ยอดเมฆทะลุระดับพาความร้อนลึกของเขตร้อน
  (235 K ≈ 10 km) — เป็นนาฬิกาทางกายภาพของเมฆ ไม่ขึ้นกับว่าตัวตรวจจับเห็นวัตถุครั้งแรกเมื่อไร
- **การแตกตัว:** track ลูก (`parent_id`) รับ t0 และประวัติของพ่อแม่ ถ้าพ่อแม่มี t0 แล้ว — เมฆก้อนเดียวกันที่ตัวติดตามแยกเป็น
  หลาย track ยังมีนาฬิกาเดียวกัน ไม่เริ่มนับใหม่ทุกครั้งที่แตก
- **t0_censored:** track ที่เห็นครั้งแรกก็มีแกนแล้วและไม่มีพ่อแม่ (เกิดตอนเริ่มข้อมูล / หลังข้อมูลขาด) — ยังทายได้ แต่ t0 อาจช้ากว่าจริง
- ข้อมูลขาดเกิน `ingest.max_gap_min` → นาฬิกาเริ่มใหม่พร้อมตัวติดตาม

## 3. ตัวแปร

| ตัวแปร | ความหมาย | ฟิสิกส์ |
|---|---|---|
| `t`, `b` | เวลาออกคำทำนาย, t0 ของสายตระกูล (นาที) | อายุเมฆ `t − t0` |
| `d2` | ระยะ Mahalanobis² จากจุดถึงวงรีแกน (ตัดที่ 16) | จุดอยู่ใต้แกนหรือห่างออกไปกี่เท่าของขนาดแกน (d² = 4 ≈ ขอบแกน) |
| `st_b13` | B13 ของพิกเซลที่อยู่เหนือจุดจริง | ความสูงยอดเมฆเหนือจุด |
| `st_btd` (= `btd`) | B13 − B15 ของพิกเซลเหนือจุด (split window) | เล็ก = เมฆหนาทึบ (ฝน); ใหญ่ = cirrus / ทั่งบาง (มักไม่มีฝน) |
| `d_b13_10`, `d_b13_20` | B13 ตอนนี้ − 10 / 20 นาทีก่อน ที่จุดเดิมบนพื้น | ลบ = คอลัมน์เย็นลง: ยอดเมฆสูงขึ้นหรือแกนเคลื่อนเข้ามา |
| `d_btd_10` | BTD ตอนนี้ − 10 นาทีก่อน | ลบ = เมฆเหนือจุดหนาขึ้น |
| `warm_20` | max(`d_b13_20`, 0) | คอลัมน์อุ่นขึ้น: แกนผ่านไปแล้วหรือกำลังสลาย |
| `depth_6` | B13 ต่ำสุดในรัศมี ~6 km ของจุด − 235 K | ลบมาก = มียอดเมฆลึกมากใกล้จุด (กระแสอากาศขึ้นแรง) |
| `clock_prior` | ln(เวลาที่นาฬิกา Weibull ทายว่าเหลือ + 10 นาที) | ข้อมูลวงจรชีวิตเมฆ ส่งต่อให้ hazard รายช่วง |

**parallax:** ยอดเมฆสูง H ปรากฏเยื้องออกจากจุดใต้ดาวเทียม (0°, 140.7°E) ไปประมาณ H·tan(SAZ) (เหนือไทย ~13–21 km สำหรับยอดเมฆ 200 K)
- พิกเซลเหนือจุด: แก้ทุกพิกเซลด้วยความสูงของตัวเอง H = (300 − B13) / 6.7 km แล้วเลือกพิกเซลที่ตำแหน่งจริงห่างจุด ≤ 1.5 km
  (หลายพิกเซล → เลือกที่เย็นที่สุด เพราะเมฆสูงบังเมฆต่ำ)
- ศูนย์กลางแกน: เลื่อนทั้งรอยด้วยเวกเตอร์เดียวจาก T_p5 ของรอย (เปอร์เซ็นไทล์ 5 ของ B13)
- หน้าต่าง `depth_6`: ย้อน parallax ของยอดเมฆเย็นสมมติ 220 K

## 4. สมการ

### 4.1 นาฬิกา Weibull (รู้อายุเมฆ)

ให้ u = t_เหตุการณ์ − t0 + 60 นาที (บวก 60 เพื่อให้เหตุการณ์ที่เกิดก่อน t0 ไม่เกิน 1 ชม. ยังเป็นบวก) และ s = t − t0 + 60

```
S(u) = exp(−(u/λ)^k)                    ความน่าจะเป็นที่ยังไม่เกิดถึงเวลา u
ln λ = a + b1·z(d2) + b2·z(btd)        z = มาตรฐานด้วยค่าเฉลี่ย / SD ของข้อมูลปรับเทียบ
```

เมื่อถึงเวลา t เหตุการณ์ยังไม่เกิด (เมฆรอดมาถึงอายุ s) ควอนไทล์ q ของเวลาเหตุการณ์คือ

```
u_q = λ·[ (s/λ)^k − ln(1 − q) ]^(1/k)          เวลา = t0 − 60 + u_q
P(เกิดภายใน L นาที) = 1 − exp( (s/λ)^k − ((s + L)/λ)^k )
```

- k > 1 = อัตราเกิดเหตุการณ์เพิ่มตามอายุ — เมฆ "แก่" ลง ยิ่งอายุมากยิ่งใกล้เหตุการณ์
  (ค่าที่ติดมากับโค้ด k ≈ 1.65 ฝนเริ่ม, 1.72 ฝนหนักสุด, 1.95 ฝนหยุด)
- b2 > 0: BTD เหนือจุดเล็ก (เมฆหนา) → λ เล็ก → เหตุการณ์มาเร็ว; b1 > 0: จุดไกลแกน → ช้ากว่า
- 4 ค่าคงที่ (k, a, b1, b2) + ตัวขยายช่วง c: q_ส่งออก = q50 + c·(q − q50) ปรับให้ช่วง 50 / 80 % ครอบคลุมตามชื่อ

### 4.2 hazard รายช่วง (อัตราเกิดเหตุการณ์ทีละช่วง 10 นาที)

แบ่งอนาคตเป็นช่วง k = 1 … 18 (3 ชม.) ความน่าจะเป็นที่เหตุการณ์เกิดในช่วง k ถ้ายังไม่เกิด:

```
h_k = logistic( a0 + a1·ln k + Σ_j β_j·z_j + Σ_j∈tv γ_j·z_j·ln k )
F(10k นาที) = 1 − Π_{i ≤ k} (1 − h_i)
```

- ควอนไทล์ q = เวลาที่ F ถึง q (เทียบเชิงเส้นภายในช่วง); เกิน 3 ชม. ใช้หางของนาฬิกา Weibull
- P30 / P60 ของฝนเริ่ม = F(30), F(60)
- γ·z·ln k คือ **ผลที่เปลี่ยนตามระยะ**: สัญญาณของคอลัมน์อากาศเหนือจุดบอกได้มากเมื่อเหตุการณ์ใกล้ และจางลงเมื่อไกล
  (สิ่งที่นาฬิกาวงจรชีวิตอย่างเดียวทำไม่ได้)
- 8 ค่าคงที่ต่อเหตุการณ์ (a0, a1, β × 4, γ × 2) + นาฬิกา Weibull ของเหตุการณ์นั้นผ่าน `clock_prior`; ฟิตด้วย logistic regression แบบ L2 (C = 1)

### 4.3 ตัวแปรของแต่ละเหตุการณ์ (ฟิสิกส์ต่างกัน)

| เหตุการณ์ | z | ผลตามระยะ (tv) | ฟิสิกส์ |
|---|---|---|---|
| ฝนเริ่ม | clock_prior, st_btd, d_b13_10, d_btd_10 | st_btd, d_b13_10 | คอลัมน์เหนือจุดหนาขึ้นและเย็นลง → เมฆเหนือจุดลึกและหนาพอจะมีฝนตกถึงพื้น |
| ฝนหนักสุด | clock_prior, st_btd, d_b13_10, depth_6 | st_btd, depth_6 | ฝนหนักสุดมาพร้อมกระแสอากาศขึ้นแรงที่สุด = ยอดเมฆลึกที่สุดใกล้จุด |
| ฝนหยุด | clock_prior, st_btd, warm_20, d_btd_10 | warm_20, d_btd_10 | คอลัมน์อุ่นขึ้นและบางลงเมื่อแกนผ่านไปหรือสลาย |

**ฝนหยุดใช้ตัวสลับ:** ใช้ hazard รายช่วงเมื่อตัวมันเองทายว่าเหลือ ≤ 30 นาที ไม่งั้นใช้นาฬิกา Weibull
(ตัดสินจากคำทำนายของตัวเอง ไม่ใช่เวลาจริง) — สัญญาณอุ่นขึ้น / บางลงชัดเมื่อใกล้หยุด ส่วนระยะไกลวงจรชีวิตเมฆบอกได้ดีกว่า

**ลำดับในผลที่ส่งออก:** สามเหตุการณ์ทายแยกกัน จึงจัดให้ เริ่ม ≤ หนักสุด ≤ หยุด ในทุกควอนไทล์ก่อนส่งออก

### 4.4 จับคู่จุดกับเมฆ

แต่ละจุดใช้สายตระกูลที่วงรีแกนใกล้ที่สุด (d² ต่ำสุด) และทายเฉพาะเมื่อ d² < 16 (อยู่ภายใน 4σ ของแกน)
รายวัตถุประเมินที่จุดใต้ศูนย์กลางแกน (d² = 0)

## 5. ผลในญี่ปุ่น (ค่าคงที่ที่ติดมากับโค้ดปรับเทียบจากที่นี่)

ข้อมูล: ภาพ Himawari ทุก 10 นาทีเหนือภาคคันโต / คันไซ ฤดูร้อน, ความจริง = มาตรวัดฝน 10 นาทีของ JMA (AMeDAS)
ที่ระดับสถานี; เมฆจากตัวติดตามแบบทีละภาพแบบเดียวกับ convrain

**นาฬิกา Weibull เทียบนาฬิกาตายตัว (t0 + ค่าคงที่) บนปีที่ไม่ได้ใช้ปรับเทียบ (38 วัน, ~220–260 คู่สถานี–เมฆต่อเหตุการณ์):**

| เหตุการณ์ | MAE นาฬิกา Weibull (นาที) | MAE นาฬิกาตายตัว | ช่วง 50 / 80 % ครอบคลุมจริง | ถูกภายใน ±30 นาที เมื่อเหตุการณ์อยู่ห่าง 30–60 นาที |
|---|---|---|---|---|
| ฝนเริ่ม | 34.6 | 44.3 | 53 / 79 % | 91 % |
| ฝนหนักสุด | 37.8 | 47.1 | 52 / 81 % | 87 % |
| ฝนหยุด | 33.9 | 45.4 | 50 / 77 % | 84 % |

**hazard รายช่วงเทียบนาฬิกา Weibull (ตรวจไขว้แบบเว้นทีละวัน, 63 วัน), % ที่คลาดไม่เกิน ±15 นาที เมื่อเหตุการณ์อยู่ห่าง 10–30 นาที:**
ฝนเริ่ม 37 → 45 %, ฝนหนักสุด 29 → 44 % (MAE 37.6 → 35.0 นาที), ฝนหยุด (ตัวสลับ) ≈ นาฬิกา Weibull;
hazard รายช่วงของฝนหยุดแม่นที่สุดเมื่อหยุดอีก 30–60 นาที (71 % ภายใน ±15 นาที)

**ลักษณะความคลาดเคลื่อน:** แม่นที่สุดเมื่อเหตุการณ์อยู่ห่าง 30–60 นาที; ถ้าห่างเกิน 1–2 ชม. คำทำนายมักเร็วไป และ 10 นาทีสุดท้าย
มักช้าไป เพราะภาพอินฟราเรดเห็นยอดเมฆ ไม่เห็นตัวฝน — ฝนอยู่ในส่วนเล็กๆ ใต้แกนเย็น ตำแหน่งที่ฝนตกจริงระบุได้ราว ±10 km
ซึ่งที่ความเร็วเมฆ ~20–25 km/ชม. เท่ากับความไม่แน่นอนของเวลา ~25 นาที

## 6. ค่าคงที่สำหรับไทย และการปรับเทียบใหม่

`config/default.yaml` ส่วน `timing` ตั้งค่าของไทยแล้ว:

| ค่า | ไทย | เหตุผล |
|---|---|---|
| `footprint_k` | 238 K | ขอบรอยเมฆพาความร้อน |
| `core_k` | 235 K | ระดับพาความร้อนลึกของเขตร้อน (โทรโพพอสไทยสูงกว่าญี่ปุ่น → เกณฑ์เย็นกว่าญี่ปุ่น 10 K) |
| `parallax_top_k` | 220 K | ยอดเมฆเย็นทั่วไปของเขตร้อน |
| `core_min_px` | 4 | = `detect.min_area_px` |
| `d2_max` | 16 | ภายใน 4σ ของแกน |

ญี่ปุ่นใช้ `config/japan.yaml` (รอยเมฆ 248 K, แกน 245 K, parallax 230 K, ระดับ detect ที่เย็น 2 ระดับ +10 K):
ยอดเมฆลึกของญี่ปุ่นอุ่นกว่าไทยราว 10 K เพราะโทรโพพอสต่ำกว่า ส่วนเกณฑ์ที่ผูกกับเฟสน้ำแข็ง (273 / 253 K) เท่ากัน

ตัวแปรของโมเดลเป็นค่าสัมพัทธ์ (ผลต่างอุณหภูมิ, BTD, ระยะ, อายุ) หรือวัดเทียบ `core_k` ของภูมิภาค จึงใช้ค่าคงที่ที่ติดมากับโค้ด
(`params.py`) กับไทยได้โดยตรง และปรับเทียบใหม่ด้วยข้อมูลฝนของไทยได้:

```bash
# 1) replay พร้อมจุดที่มีข้อมูลฝน แล้วเก็บแถวสำหรับปรับเทียบ
python scripts/replay.py --scans-dir data/scans --points gauges.csv --out runs/sep --collect-timing-rows --no-json
# 2) ฟิตค่าคงที่ใหม่ (ฝนที่จุด: key, time + rain_mm_10min หรือ dbz)
python scripts/calibrate_timing.py --rows runs/sep/timing_rows.parquet --rain rain_points.csv --out models/th1
# 3) ประเมินแบบเว้นทีละวันเทียบนาฬิกาตายตัว (--builtin = ประเมินค่าที่ติดมากับโค้ด)
python scripts/evaluate_timing.py --rows runs/sep/timing_rows.parquet --rain rain_points.csv --out reports/th1
# 4) ใช้ค่าใหม่
python scripts/run_realtime.py --watch-dir INCOMING --out nowcast --models-dir models/th1 --points points.csv
```

**นิยามเหตุการณ์ที่จุด** (ใช้ตอนปรับเทียบ / ประเมินเท่านั้น): ฝนเป็นช่วง 10 นาที, เกณฑ์ 0.5 มม. / 10 นาที (≈ 3 มม./ชม. ≈ 30 dBZ
ด้วย Marshall–Palmer); ฝนเริ่ม = ช่วงแรกที่ถึงเกณฑ์, ฝนหนักสุด = ช่วงที่มากที่สุด, ฝนหยุด = ปลายช่วงเปียกสุดท้ายก่อน
ช่วงแห้ง 2 ช่วงติดกันแรกหลังฝนหนักสุด (แห้ง ≥ 20 นาที กันการหยุดหลอก); หน้าต่าง = [t0 − 60, ออกคำทำนายครั้งสุดท้าย + 90 นาที]
เรดาร์ทุก 10–15 นาทีใช้ได้ (แต่ละช่วงใช้ภาพที่ใกล้กลางช่วงที่สุด ±8 นาที); มาตรวัดฝนรายชั่วโมงหยาบเกินไปสำหรับนิยามนี้
ข้อมูลฝนใช้ปรับเทียบ / ประเมินเท่านั้น ไม่เป็นข้อมูลเข้าตอนรันจริง

## 8. ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `timing.py` | `ScopeTiming.step(scan, tracks)` → `TimingResult(objects, points)`; โหลดค่าคงที่ / จุด |
| `lineage.py` | `LineageBook`: สายตระกูล, t0, สถิติรอย / แกน |
| `columns.py` | `ColumnSampler`: เก็บภาพ ≤ 30 นาที แล้วตอบค่าคอลัมน์ของจุดใดก็ได้ |
| `clock.py` | `WeibullClock` (นาฬิกา Weibull), `FixedClock` (นาฬิกาตายตัวสำหรับเทียบ), `widen` |
| `hazard.py` | `LightHazard` (hazard รายช่วง), `Switch`, `EVENT_FORMS`, `from_dict` |
| `calibrate.py` | นิยามเหตุการณ์ที่จุด, จับแถวกับฝน, ฟิตค่าคงที่, คะแนนตามระยะเวลา |
| `params.py` | ค่าคงที่ที่ติดมากับโค้ด |
| `geometry.py` | parallax, ระยะ, วงรีแกน, ดัชนีพิกเซลบนพื้น |
